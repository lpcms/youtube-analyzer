Основная задача создать сервис для анализа видео каналов на сайте https://www.youtube.com:
1. Авторизация не нужна, сервис будет использоваться личных целях для себя;
2. Зайдя на страницу сервиса мы видим:
 - строку для ввода адреса канала youtube - валидация сработает тогда, когда мы введём не адрес канали;
 - к-во видео, тут нужно иметь возможность ввести кодичество видео в цифрах или возможность выгрузить все видео;
 - Галочка Video - по умолчанию выбрана - если выбрана загружаем аналитику Video;
 - Галочка Shorts - по умолчанию выбрана - если выбрана загружаем аналитику Shorts;
 - Кнопка "Начать".
3. Если все поля из п.2 валидны и нажата кнопка "Начать" сервис берёт указанные/все Video и/или Shorts указанного канала и составляет таблицу с таким полями:
 - URL - ссылка на видео, кликабельная в новом окне открывается;
 - Тип - Video / Shorts;
 - Длительность - тут вывести продолжительность Video / Shorts;
 - Просмотры - тут вывести количество просмотров;
 - Лайки - тут вывести количество лайков;
 - ДизЛайки - тут вывести количество дизлайков;
 - Комментарии - тут вывести количество комментариев;
 - Вирусность - тут нужно определять вирусность нашего видео по формуле учитывая Просмотры, Лайки, Дизлайки, Комментарии;
 - Дата - формат 2026-09-21 14:21;
 - Описание - вывести описание Video / Shorts, если есть.
4. Нужно сформировать очень структурированную и лакончиную, функциональную, сортируемую, если нужно с разбивкой по страницам таблицу по данным из п.3.
5. Сделать возможность быстро выгрузить / скачать данные в таблицу Эксель - кнопка "Скачать таблицу".
6. Приватный репозиторий https://github.com/lpcms/youtube_analyzer.git - ключ у нас уже должен быть, проверь в любом случае.
7. Первое, что нужно сделать:
 - скиллы и изменить данные под наш проект и наш реполиторий; 
 - создать файл клода
 - проанализировать наше ТЗ;
 - сформировать задачи по скиллам prd;
 - и все задачи и подзадачи оформить разместить в github issues (на языке ru) используя склилл issues;
 - то есть используя скиллы нужно правильно всё спланировать, а потом уже, после моей проеверки планов в github issues начать работу.
8. Проект слелай на Next.js + React + EsLint + SQLite, или на твоё усмотрение можешь использовать технологии, чтобы получиться максимальную производительность.
9. В репозитории https://github.com/lpcms/youtube_analyzer.git будем работать через issues и там формировать и отмечать задачи.
