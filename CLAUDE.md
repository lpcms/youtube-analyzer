# youtube_analyzer

Сервис анализа видео YouTube-канала для личного использования. Пользователь вводит
адрес канала, получает таблицу его Video и Shorts с метриками и выгружает её в Excel.

Источник требований — `tz.txt` в корне. Репозиторий — `lpcms/youtube_analyzer` (приватный),
работа ведётся через GitHub issues.

## Стек

- **Next.js 15**, App Router, серверные действия. React 19, TypeScript в strict-режиме.
- **Prisma + SQLite** (`better-sqlite3`) — кэш выгрузок, чтобы повторный запрос
  того же канала не тратил квоту API.
- **YouTube Data API v3** — единственный источник данных.
- **Tailwind CSS** — оформление. **TanStack Table** — сортировка и пагинация.
- **Vitest** + React Testing Library + MSW — модульные и интеграционные тесты.
  **Playwright** — E2E.
- **ESLint** + Prettier.

## Команды

```
npm run dev            # дев-сервер
npm run build          # прод-сборка
npm run lint           # ESLint
npm run typecheck      # tsc --noEmit
npm run format:check   # Prettier, проверка
npm run format         # Prettier, исправление
npm test               # Vitest: модульные и интеграционные
npm run test:coverage  # покрытие
npm run test:e2e       # Playwright
npm run verify         # format:check + lint + typecheck + test
```

`npm run verify` должен быть зелёным перед каждым коммитом. Полный регламент
из девяти этапов — `docs/testing-cycle.md`, прогоняется скиллом `test-cycle`.

## Конвенции

**Счётчики различают ноль и отсутствие.** У видео с отключёнными лайками или
комментариями API возвращает поле отсутствующим — это `null`, а не `0`. В таблице
выводится «н/д». Формула вирусности обязана такой случай пережить.

**Длительность хранится в секундах** целым числом. API отдаёт ISO 8601 (`PT1M30S`);
разбор и форматирование — отдельные функции со своими тестами.

**Даты хранятся в UTC**, в таблице выводятся как `2026-09-21 14:21`. Собственного
форматирования через `toLocaleString` не использовать — формат из ТЗ фиксирован.

**Ключ API живёт только на сервере.** Переменная `YOUTUBE_API_KEY` без префикса
`NEXT_PUBLIC_`. Обращения к YouTube — только из серверного кода.

**Описание видео выводится как текст**, никогда как HTML: в описаниях бывает
произвольная разметка и ссылки.

**Вся валидация входа — через zod**, на сервере, а не только в форме.

## Дизлайки

Столбца дизлайков в проекте нет. YouTube убрал публичные дизлайки в декабре 2021,
API их не отдаёт, а сторонние сервисы дают оценку, а не факт. Это сознательное
отступление от п.3 ТЗ, зафиксированное в PRD. Формула вирусности построена
на просмотрах, лайках и комментариях.

## Квота API

10 000 единиц в сутки. `search.list` стоит 100 единиц за вызов и потому не
используется для перебора видео: список берётся через `playlistItems.list`
(1 единица за 50 видео) из плейлиста загрузок канала, метрики — через
`videos.list` (1 единица за 50 видео). Исчерпанная квота — штатная ситуация,
у неё должно быть понятное сообщение в интерфейсе, а не пятисотка.
